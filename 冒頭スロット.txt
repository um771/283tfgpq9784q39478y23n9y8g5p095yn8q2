; ============================================================
; 冒頭スロット.txt  ― 意味スロット辞書（SlotEngine 用）
; ------------------------------------------------------------
; ■ フォーマット
;   #PREFIX / #SUFFIX … 生成文の前後に必ず付く固定部分
;   #SLOT スロット名   … 以降の行がそのスロットに入る語彙（1行1語）
;   #FRAME             … 以降の行が文型。スロット名を { } で囲んで並べる
;   ; 行頭セミコロン    … コメント
;
; ■ 語彙行の書き方
;   本文 @タグ ^グループ=値
;   ・語彙は「接続に必要な助詞込み」で書く。フレームは並べるだけなので、
;     ここで助詞を間違えると文法が壊れる。必ず助詞込みで書くこと。
;   ・本文に空白を入れない。空白以降はタグとして解釈される。
;   ・@タグ … フレーム側から {場所@屋内} のように候補を絞り込める。
;   ・^グループ=値 … 排他指定。同じグループで違う値が同時に選ばれた
;     組み合わせは不合格になり、自動で引き直しになる。
;     値を付けない語彙は「どの値とも両立する」汎用語彙として扱われる。
;   ・同じグループの値の表記は統一する（^場面=自宅 と ^場面=家 を混ぜない）。
;
; ■ 使っているグループ
;   ^場面     = 自宅 / 公共 / 屋外 / 学校 / 職場 / 店
;   ^主体     = 自分 / 他者
;   ^属性     = 物 / 人 / 音 / 光 / 気配 / 液体 / 気体 / 機械 / 文字
;   ^助数詞   = 枚 / 足 / 台 / 段 / 本 / 人 / 回
;   ^媒体     = 紙 / 写真 / 札
;
; ■ 拡張のしかた
;   #SLOT に行を1行足すだけで、そのスロットを使う全文型のパターン数が
;   掛け算で増える。#FRAME に1行足すと新しい骨格が増える。
;   既存行と一致した文が出ても問題ないので、語彙追加だけを意識すればよい。
; ============================================================

#SLOT 気づき
; ============================================================
ことに気づく
ことに、その場では気づかない
ところから始まる
ところで足が止まる
のを目にして、理由が分からないまま進む
ことを後になって知る
のに、誰も気に留めない
ことに、最後まで理由が分からない
と、周囲の音が止まる
ことに、その日から同じことが繰り返される
のを見て見ぬふりをする
ことに、家へ戻ってから思い出す
ことに気づくが、振り返れない
ことに、日が昇ってから気づく
のに、理由が分からない
ことに、誰も口に出さない
ことに、その日はそのまま過ぎる
ことに、歩いている間に夜が明ける
のに、自分はそれを覚えていない
ことに、理由が最後まで分からないまま進む
と、その日から一日が始まらない
ことに、あとになって意味が変わる
