; ============================================================
; 終盤スロット.txt  ― 意味スロット辞書（SlotEngine 用）
; ------------------------------------------------------------
; 伏線は「言葉系／物系／身体・状況系／死系」の4グループに分け、
; それぞれ接続の合う作用述語（〜が／〜を で受ける形）としか
; 組み合わさらない。死系は、人物が死ぬ流れを構成するグループ。
; 死に場（時・場所）と死に方（手段）と死に目的（理由）の
; 3要素の直積で形になる。
; 帰結は、動作の対象と同じドメインを持つ専用スロット
; （帰結_言／帰結_物／帰結_状）と、死のフレームだけを使う
; 帰結_死に分かれる。帰結スロット間で項目を共用しない。
; 帰結は「それが〜」の形で動作の対象を指すものと、伏線の
; 内容を名指すものの2形を持ち、いずれも過去の要素を現在の
; 原因として結ぶ内容である。
; 帰結は物語の状態（情報・条件・力関係・構造）を不可逆に
; 変える内容のみを持ち、感情の名称や気分の提示は入れない。
; 帰結_死は、本編の中で起こる死（誰が・どう・何人死ぬかの
; 発生と確定）のみを書く。死を主語にする現在形（死ぬ／
; 息絶える／死体が見つかる）で書き、すでに死んでいる者の
; 遺留品・生前の計画・過去の真相は置かない。
; 死に方には、投げ出し・偶然・未提示の要因（運命・事故・
; 突然の病など）を入れない。
; 書式・拡張のしかたは 冒頭スロット.txt と同じ。
;
; ■ 使っているグループ
;   ^当事者 = 主 / 相 / 単 / 複 / 全
;   ^系     = 一般 / 能力   （能力系の述語を能力系の伏線に限定する）
; ============================================================
