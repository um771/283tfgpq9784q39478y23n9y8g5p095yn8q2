ハイン（ 从 ﾟ∀从 ）は線路工事の支度をしていた。

夜明け前の駅舎の奥、保管庫の角で、工具箱の中身を確認する。スパナ、ペンチ、緊急用の信号具。標準的な朝の準備だ。午前6時、上り電車が通るまでに線路上の落下物を片付け、架線に異常がないか確認する。それが仕事。

給与は月12万5千円。11年勤続。交通費は別。休日は月8日。

ハインは給与明細をスマートフォンで眺める。先月、昇給は見送られていた。理由の欄には「人事評価検討中」とある。つまり、ない。

同期の作業員は既に昇進していた。彼は線路上の作業より事務の片隅に移ったと聞いた。同じ時期に採用されたのに、何が違うか。ハインは別に能力で劣っていない。むしろ現場では頼られている。なぜなら、彼は余計なことを言わないからだ。

朝日が線路の上に落ちた。

ハインは保管庫から出て、支給されたベストを着た。反射板が3箇所。これでドライバーに見える。安全が大事。会社がいつも言う言葉だ。

線路を歩く。枕木と枕木の間に何か落ちていた。ビニール袋。中身は見えない。ハインはペンチで挟んで拾った。缶のような重さ。

駅舎に戻ると、駅長がいた。60代。30年この駅にいるらしい。

（ 从 ﾟ∀从 ）「落下物です」

（ﾟ∀ﾟ）「中身は」

（ 从 ﾟ∀从 ）「確認していません。持ち込まれたのは1時間前。線路上にありました」

駅長はビニール袋を開けた。缶が2本。マスターベースという工業用溶剤だった。

（ﾟ∀ﾟ）「これ、危険物扱いだ。どこから落ちたのか」

（ 从 ﾟ∀从 ）「不明です。上り電車の最後尾から、と推測されます。昨晩の23時台」

駅長は缶を持ち直した。ラベルは剥がれていない。製造年月は去年の11月。

（ﾟ∀ﾟ）「これ、報告書に上げとくわ。ハイン、お前が拾ったことは書くが、具体的には『駅周辺の巡回中に発見』ぐらいにしとく。面倒な質問来るからな」

（ 从 ﾟ∀从 ）「わかりました」

（ﾟ∀ﾟ）「怪我もしなかったし、これで終わり。線路の一周目、頼む」

ハインは線路をもう一度歩いた。架線に異常なし。石礫の状態も正常。6時17分、上り電車が到着した。乗客45名。全員下車。何も起きなかった。

線路工事の支度は終わった。日勤の時給は1150円。時間給だから、給与は秒刻みで加算される。朝の準備は30分。450円の仕事だった。

9時。ハインは架線上部の絶縁体を点検していた。梯子の上、20メートル。足元は枕木と石礫。風が強い日だった。

駅では何も起きていない。缶の件は既に忘れられているだろう。駅長は午後に報告書を上げるだろう。ハインの名前は「発見者」の欄に書かれる。それで給与は増えない。報告義務を果たすだけだ。

12時。昼休憩。駅舎の休憩室で弁当を食べた。米、卵焼き、野菜。400円で買ったものだ。妻が作ったのではなく、コンビニの商品。妻は今、別の駅舎で清掃業務をしている。給与は時給950円。

ハインは弁当を食べながら、スマートフォンでニュースを見た。

「重大な産業事故。A化学工場での爆発。死傷者23名。原因は不明。調査中」

その工場は5キロメートル先にあった。朝のニュースには出ていなかった。つまり、今朝の事故。

工業用溶剤の落下時刻は23時台。事故は今朝。時間が合わない。

ハインはスマートフォンをしまった。別の駅からの報告だろう。そういうこともある。

15時。ハインは再び線路上にいた。今度は下り線の点検。この線路は朝より人通りが少ない。貨物列車が1本、定期で通過する。乗客なし。重量物だけ。

線路の枕木に、白いペンキの落書きがあった。「ここまで」と書かれていた。矢印が付いている。矢印が指す先は、駅舎から南西3キロメートルの地点。その先は鉄道管轄外。私有地だ。

ハインは報告書に記載することにした。落書きは安全上の問題ではない。ただし、記載する義務がある。

駅長に報告すると、駅長は即座に指示を出した。

（ﾟ∀ﾟ）「了解。ただし、これも詳しく書かないこと。『線路上に表記あり。確認した』程度」

（ 从 ﾟ∀从 ）「わかりました」

（ﾟ∀ﾟ）「何かあると面倒だからな」

ハインは報告書を書いた。その日は18時に退勤した。

妻は19時に帰ってきた。妻の名は由美。40代。結婚して15年。子供はいない。

（由美）「今日も暑かった。足が腫れてる」

（ 从 ﾟ∀从 ）「水に浸してみたら」

（由美）「そんなことで治るわけない。給与上げてくれよ」

（ 从 ﾟ∀从 ）「昇進試験、受ければいい」

（由美）「試験料がいるし、受かる保証もない。お前だって、昇給してないじゃん」

（ 从 ﾟ∀从 ）「ああ」

（由美）「何か、やること、あるか」

ハインは台所に行った。冷蔵庫には昨日の味噌汁が残っていた。温め直す。夕食の準備は10分で完了した。

夜、ハインはベッドで思考していた。給与は増えない。昇進も見えない。生活費は毎月3万円の貯蓄で1年6万円。妻の給与を合わせても、月5万程度の貯蓄。年間60万。貯金は今210万。使い道がない限り、死ぬまでに200万増える。人生の規模では、何ひとつ変わらない。

線路は毎日、同じ轨道を走る。電車も同じ。乗客も、ほぼ同じ。違いは不安定さだけ。給与の増減。人員削減の可能性。駅の廃線化。可能性としては、ある。だが、その可能性が実現するまでは、毎日は同じ。

朝4時に起きた。早い。睡眠時間は4時間。十分でない。だが、ハインは目が冷めた。意識的に目を開けたのではなく、脳が勝手に目を覚ました。何かが違う。その感覚は、線路上での経験から来ていた。架線に異常がないか調べるとき、目視する前に、何か違う、という感覚が先にくる。その感覚は正確だった。

ハインはスマートフォンを見た。4時25分。ニュース速報があった。

「線路上での事故。貨物列車が脱線。重量物が流出。原因は調査中」

その脱線地点は、先日ハインが「ここまで」という落書きを見た地点から、南西に1キロメートルの場所だった。

ハインは布団から出た。妻は眠っていた。

駅に着いたのは5時。誰もいない。駅長も、他の作業員も来ていない。いつもなら、緊急対応で駅長が真っ先に着く。だが、今日は静かだった。

ハインは駅舎の前に立った。線路から、通常と違う音がしていた。一度だけ、聞いたことがある音。電車の急停止。ブレーキフルロック。それは、高速で何かが衝突したときに起きる音。

駅舎の無線が鳴った。本社からだ。「A駅およびB駅の駅員、本社に直接報告願う。線路上の落下物に関する聴取あり」

ハインは無線を取った。誰も応答していない。駅長はまだ来ていない。

（ 从 ﾟ∀从 ）「ハイン、応答します」

「本社駅長会議室まで直ちに出向け」

ハインは指示に従った。

本社に着いたのは6時30分。駅長は既にいた。そして、警察官も2人。

（駅長）「ハイン、昨日の缶について。詳しく説明してくれ」

（ 从 ﾟ∀从 ）「線路上にありました。ビニール袋に入った状態。マスターベースという工業用溶剤。2本」

（ 从 ﾟ∀从 ）「朝6時前に発見。上り電車からの落下と推測」

（警察官）「いつ」

（駅長）「昨日の16時」

（ 从 ﾟ∀从 ）「駅舎から南西3キロメートル。下り線の枕木」

警察官はメモを取った。

警察官は黙った。もう一人の警察官も黙った。駅長は顔を伏せていた。

（警察官）「今後、あんたがどう扱われるかは、司法が決める。それまでは、これ以上の発言はするな」

ハインは頷いた。

その後の調査で、脱線は最低限の被害に留まった。それでも6人が負傷した。うち1人は脊椎損傷で、今後の回復が不透明だった。

駅長は解職され、別の処罰を受けることになった。ハインは聴取を受け、その後、社内委員会で処遇について議論されることになった。

結果として、ハインは降格された。給与は月11万2千円に減給された。同時に、別の支所への異動が命じられた。そこは時給がさらに100円低い地点だった。

妻は、その夜、何も言わなかった。弁当を食べるとき、箸の動きが止まっただけだ。

ハインは、給与計算機を取り出して、新しい月収を計算した。月279時間労働として、時給1050円。月額292,950円。昨月からの減給額は、月9,600円。年間115,200円の損失。

貯蓄は、毎月4万円に減った。人生の規模では、さらに小さくなった。

翌朝。ハインは新しい支所に向かった。そこは、廃線予定の区間だった。
