❓ 使い方・仕組み

◆ 使い方

  • このページをブラウザで開いて、「🚀 ワンクリック生成＆コピー」を押すだけ。
  • 生成されたプロンプトは自動でクリップボードにコピーされ、下の欄にも表示されます。そのままAI（ChatGPT等）に貼り付けて小説を生成してください。
  • 実行のたびに「選出パターン（ブーン／モナー／他の人／マルコフ）・視点・テーマ・トーン・文字数」がランダムに変わります。

◆ データはどこから来るの？（GitHub参照）

  • デフォルトでは GitHub リポジトリ um771/283tfgpq9784q39478y23n9y8g5p095yn8q2 の main ブランチにある SS.txt / 二次創作.txt / 超加速.txt / 他の人.txt / マルコフ.txt / トーン.txt / 最後.txt を raw.githubusercontent.com から取得します。
  • マルコフ.txt や 最後.txt をリポジトリ上で編集して保存 → このページで生成 すれば、最新版が反映されます（毎回最新を取得）。
  • 取得に失敗した場合は「前回取得した内容」を自動で使い、警告を表示します。
  • リポジトリを変えたい場合は「⚙ 設定」のリポジトリ欄を書き換えるか、各ファイルのURLを直接編集してください。

◆ ローカルファイルを使う場合

  • 設定の各ファイル行で「参照元」をローカルファイルに切り替え、📁 ボタンで選択します。
  • Chrome / Edge なら選択したファイルを記憶し、毎回最新の内容を読み込み直します（ファイルを編集→生成、が反映される）。
  • 他のブラウザでは選択内容をキャッシュします（ファイル変更時は再選択）。
  • 「テキスト直接入力」にすると、画面内の欄に内容を貼り付けて使えます。

◆ 保存機能（改稿システム用）

  • genprompt.txt … AIへ渡したプロンプト全文（元pyの write_genprompt 相当）。
  • 00_world.md / 01_characters.md … 採用された資料を機械分割したもの（元pyの write_split_files 相当）。
  • 生成後に各ボタンで保存できます。

◆ エラーが出るとき

  • GitHub取得に失敗する場合：①ネットワーク確認 ②リポジトリ名・ブランチ名の確認 ③参照元を「ローカルファイル」に変更。
  • ブラウザの制限で取得できない環境（まれ）では、このHTMLをGitHubリポジトリに index.html として置き、 GitHub Pages（Settings → Pages → Deploy from branch）で公開すれば確実に動きます。
  • クリップボードコピーが効かない環境では、下の欄から手動コピーしてください。
  • 設定はこのブラウザに自動保存されます。「すべて初期状態に戻す」でリセットできます。

◆ 移植メモ

  • 「生成py_組み込み済み.py」のロジック（マルコフ連鎖・パターン抽選・トーン配合・視点・テール処理・資料分割）をJavaScriptへ忠実に移植しています。
  • Python側と出力が一致すること（strip_markdown・マルコフ統計・分割ファイル）をテストで確認済みです。
  • 元pyの絶対パス（C:\Users\...）の代わりに、ファイルごとの「参照元」で切り替えます。
