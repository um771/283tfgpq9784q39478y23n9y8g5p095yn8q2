; ============================================================
; 冒頭骨格.txt ― 構造層辞書（骨格エンジン用）
; ------------------------------------------------------------
; 「日常→異変発見→調査・逃走」への収束を防ぐため、冒頭の1文を
; 「物語骨格カード（軸の組合せ）→ 文章化」の二層で作る。
; 表現のバリエーションではなく、物語機能（何が物語を動かし始めるか）
; を分散させることが目的。
;
; ■ フォーマット
;   #AXIS 軸名      … 以降の行がその軸の値。カードは各軸から1値を選ぶ
;   #SLOT スロット名 … 以降の行が語彙（カードには入らない Variety 用）
;   #TEXT           … 以降の行が文型フレーム。{ } でスロットを並べる
;   #PREFIX / #SUFFIX … 生成文の前後に付く固定部
;   #KEY 軸名…      … 意味的重複のリジェクションで比べる軸だけを並べる。
;                     書かない場合は全軸を比べる
;   ; 行頭セミコロン … コメント
;
; ■ 値行・語彙行・フレーム行に付けられる制御トークン
;   重みn        … 抽選重み（省略時1）
;   @軸=値       … 条件。カードのその軸の値が一致する場合のみ選ばれる（| で OR）
;   !軸=値       … 条件。カードのその軸の値が一致する場合は選ばれない（| で OR）
;   ^グループ=値 … 排他指定。カードに書き込まれ、@グループ=値 の条件にも使える
;   @タグ        … 裸タグ。フレーム側の {スロット@タグ} で語彙を絞り込む
;   文{…}        … 軸値の文章化テンプレート（述語を含む文として展開する）
;   句{…}        … 軸値の文章化テンプレート（名詞句として展開する）
;                  同じ種類を複数書くと先頭から試し、語彙が引けたものを使う
;   文=文字列     … 軸値をその文字列のまま展開する（テンプレートを使わない指定）
;
; ■ テンプレート（文{…}／句{…}）の中身
;   部品は + で区切る。波括弧は書かない。
;     スロット名        … 語彙プールから1語
;     スロット名?       … 候補が無ければ省略
;     スロット名@タグ    … 裸タグで絞り込む（複数可：スロット名@タグ1@タグ2）
;     スロット名@#軸名   … 裸タグの位置に #軸名 を書くと、その軸の値をタグにして絞り込む
;     スロット名が「・」で終わるときは、先頭の #軸名 の値をスロット名に
;                      連結して語彙プールを引く（被り名詞・@#被り対象 → 被り名詞・道具）
;     #軸名            … 軸値を展開する（その軸値にテンプレートがあればそれを展開）
;     #軸名?           … 軸が引かれていなければ省略
;     =文字列          … その文字列をそのまま出す
;
;   軸値テンプレートが複数あるときは先頭から試し、語彙が引けたものを使う。
;   ただし文法の一致はテンプレートの数ではなく、語彙と軸に付けた
;   @文法クラス=… の条件で担保する（テンプレートは文と句の2つだけにする）。
;
; ■ フレーム内・テンプレート内の参照
;   {#軸名}           … カードが選んだ軸の値を展開する。その軸値に 文{…}/句{…} が
;                       あればテンプレートを展開した文を返す
;   {スロット名}      … 語彙プールから1語展開する
;   {スロット名?}     … 候補が無い場合は省略する
;   {スロット名@タグ} … 語彙を裸タグで絞り込む
;   {スロット名@#軸名} … 裸タグの位置に #軸名 を書くと、カードのその軸の値を
;                       タグとして解決して絞り込む。スロット名が「・」で終わる
;                       ときは、その値をスロット名に連結して語彙プールを引く
;   {#軸名=句}      … 軸値を名詞句のテンプレートで展開する（既定は 文）
;
; ■ 軸を足すときの注意
;   1. ^グループ=値 のグループ名は辞書全体で一意にする。
;      同じグループ名を別の軸が別の値で使うと、後から引かれる軸が
;      排他で全滅して、その軸が丸ごとカードに出なくなる。
;   2. 文法クラスのように語彙と軸の双方を縛る軸は、
;      縛られる軸と語彙より前に引くこと。
;   3. 文法が複数ある軸値は、文法ごとに軸値のエントリを分け、
;      それぞれに @文法クラス=… の条件を付ける。
;      テンプレートを同じ軸値に並べても、文法の一致は保証されない。
;   4. 合成した軸は、それを使う文型のエンジンだけで引くように
;      @冒頭の型=… / !冒頭の型=… の条件を付ける。
;   5. テンプレートの部品に波括弧を付けない。
;      文{A+=の+B} は正しいが、文{#A}+=の+{#B} は部品名が壊れて必ず空振りする。
;   6. 字面は必ず = を付ける。文{A+=の+B} の = の有無で意味が変わり、
;      文{A+の+B} と書くと「の」が語彙プール名として探され、必ず空振りする。
;   7. 軸値のテキストは engine が観測頻度を数えるキーになる。
;      同じテキストのエントリを並べると互いに重みを削り合うので別名にする。
;   8. 条件は「後から引かれる側」にしか書けない。
;      壊れ方 は 被り対象 より前に引かれるため、壊れ方に @被り対象=… と書いても効かない。
;      被り名詞・（カテゴリ） の語彙側に !壊れ方=… として書くこと。
;
; ■ 問題の作り方
;   軸「合成問題」が 問題を作る・名詞/文/の を引いたときは、
;     被り対象（何が）× 壊れ方（どう壊れるか）× 発生時点 × 発生場所
;   の組合せで問題を1つ作る。語彙は 被り名詞・（カテゴリ） スロットに
;   分類してあり、合成問題は 被り名詞・@#被り対象 で被り対象の値に合う
;   スロットを引く。スロットの語彙は @文法クラス=… と !壊れ方=… で、
;   日本語として読める組合せだけに絞り込まれる。
;   完成品プールは廃止した。元の #AXIS 問題 の100語はすべて分解で再現できる。
;   分解できない固有名詞的な問題だけを完成品プールに残し、
;   分解できる問題は軸の組合せで作る。
;
; ■ 約束ごと
;   語彙は助詞込みで書く。生成時に空白はすべて除去される。
;   文の末尾になる語彙（初動文・目的文・決着部）は辞書形で書く。
;   連結部になる語彙は連用形・て形で書く。
;   抽選は 動的重み補正（直近履歴で出過ぎた値の重みを下げる）＋
;   リジェクション（直近カードと物語機能ベクトルが近い組は引き直し）で行う。
; ============================================================
