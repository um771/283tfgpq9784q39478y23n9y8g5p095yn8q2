SVP 変換器 SV1 / SV2 対応

Synthesizer V の AI ピッチを VOCALOID4 (.vsqx) / OpenUTAU (.ustx) / VoiSona (.tssln, .tssprj) へ移植します。 SV2 で廃止された「歌唱→マニュアル」変換は不要 — pitchControls から直接読み出します。 全処理はブラウザ内で完結し、ファイルはどこにも送信されません。

ピッチが無い / ラップの場合は SV2 で書き出した .wav も一緒にドロップ（複数可）
複数トラックは <曲名>_<トラック名>.wav で自動割り当て
またはクリックして選択　.svp .wav ×N .mid
FL Studio 用：.mid も一緒にドロップすると、そのMIDIに SV のピッチを乗せます
出力フォーマット
UTAU は音源の種類でボタンを選んでください。単独音＝歌詞がそのままサンプル名になる音源 （足立レイ 等）。連続音＝- あ / a あ のような VCV・CVVC 音源 （ナースロボ_タイプT 等）。間違えると音が鳴りません。
出力言語（音源の言語に合わせる — 日本語音源と英語音源で音素が違うため混在不可）

この変換の仕組み / SV2 で従来手法が使えない理由

従来手法 (SV1)： 全ノートを選択しピッチモードを「歌唱」→「マニュアル」に変更すると、 AI の生成したピッチが pitchDelta パラメータに焼き込まれ、UtaFormatix がそれを読める。

SV2 での問題： この「歌唱→マニュアル」コマンドが存在しない。 そのため pitchDelta は空のままで、UtaFormatix に通してもピッチが一切乗らない。

本ツールの解決策： SV2 は AI ピッチを別の未公開フィールド pitchControls に保存している。 これを直接デコードする：

pitchControls[i] = { pos, pitch, type:"curve", points:[dt₀,ds₀, dt₁,ds₁, …] }
絶対ピッチ(pos + dtₙ) = pitch + dsₙ　(pos=blick, pitch=絶対MIDI, ds=半音差分)

これを VOCALOID の PIT = round(偏差 ÷ PBS × 8192) に変換して書き出す。 同一曲の SV1／SV2 ファイルで検証したところ平均誤差 0.12 半音（差分は AI モデル自体の違いのみ）、 SV1 経路は UtaFormatix の出力と平均 2 セント（≒完全一致）で再現。

各フォーマットのピッチ表現：

VSQX　PIT = round(偏差半音 ÷ PBS × 8192)（PBS は自動で必要最小値）
USTX　パート内カーブ pitd（ノート音程からの偏差、単位センチ＝cents）
VoiSona　Parameter > LogF0（ln(Hz) の絶対値、Index/Repeat のランレングス圧縮）

VoiSona は JUCE の ValueTree バイナリ形式です。UtaFormatix の .tssln 書き出しはノートと歌詞だけで ピッチを出力しませんが、本ツールは LogF0 を書き込むためピッチまで移植できます。

ラップ (musicalType="rap") について： SV は仕様上ラップノートのピッチカーブを .svp に保存しません（譜面上のピッチもプレースホルダ値のまま）。 この場合は SV2 でレンダリングした .wav を一緒にドロップしてください。 YIN 音高推定でピッチを復元します（検証時の中央値誤差 2.4 セント）。 有声/無声マスクで自動的に時間ずれも補正します。
