-# JavaScript 配列メソッドまとめ
-JavaScriptの配列には便利なメソッドがたくさんあります。よく使うものを目的別に整理しました。
-## 1. 要素の追加・削除（元配列を変更する）
-	メソッド	説明	返り値	例
-	push(...items)	末尾に要素を追加	新しい配列の長さ	[1,2].push(3) → [1,2,3]
-	pop()	末尾の要素を削除して返す	削除した要素	[1,2,3].pop() → 3、配列は [1,2]
-	unshift(...items)	先頭に要素を追加	新しい配列の長さ	[2,3].unshift(1) → [1,2,3]
-	shift()	先頭の要素を削除して返す	削除した要素	[1,2,3].shift() → 1、配列は [2,3]
-	splice(start, deleteCount, ...items)	指定位置の要素を追加・削除・置換	削除した要素の配列	[1,2,3,4].splice(1,2,'a','b') → [2,3]、元配列は [1,'a','b',4]
-## 2. 部分配列の取得・結合（元配列は変更しない）
-	メソッド	説明	返り値	例
-	slice(start, end)	指定範囲の部分配列をコピー	新しい配列	[1,2,3,4].slice(1,3) → [2,3]
-	concat(...arrays)	複数の配列・値を結合	新しい配列	[1,2].concat([3,4], 5) → [1,2,3,4,5]
-	flat(depth)	ネスト配列を平坦化	新しい配列	[1,[2,[3]]].flat(2) → [1,2,3]
-	flatMap(fn)	map() + flat(1)	新しい配列	[1,2].flatMap(x=>[x,x*2]) → [1,2,2,4]
-## 3. 検索・判定
-	メソッド	説明	返り値
-	indexOf(value)	指定値の最初のインデックスを返す（見つからない場合 -1）	数値
-	lastIndexOf(value)	指定値の最後のインデックスを返す	数値
-	includes(value)	指定値が含まれるか	true/false
-	find(fn)	条件に合う最初の要素を返す	要素 or undefined
-	findIndex(fn)	条件に合う最初の要素のインデックスを返す	数値 or -1
-	some(fn)	条件に合う要素が1つでもあれば true	boolean
-	every(fn)	全ての要素が条件を満たせば true	boolean
-## 4. 反復・変換
-	メソッド	説明	返り値
-	forEach(fn)	各要素に対して関数を実行（戻り値なし）	undefined
-	map(fn)	各要素を変換した新しい配列を返す	配列
-	filter(fn)	条件に合う要素だけを抽出した新しい配列を返す	配列
-	reduce(fn, initialValue?)	累積値を計算して1つの値を返す	任意の型
-	reduceRight(fn, initialValue?)	右から左にreduce	任意の型
-	sort(compareFn)	配列を並び替える（破壊的）	配列（元を変更）
-	reverse()	配列の順序を逆転（破壊的）	配列（元を変更）
5. その他便利なメソッド
メソッド	説明	返り値
join(separator)	配列を文字列に結合	string
-	toString()	カンマ区切りの文字列に変換
concat(...arrays)	複数の配列を結合（非破壊的）	新しい配列
slice(start, end)	部分配列をコピー（非破壊的）	新しい配列
-	splice(start, deleteCount, ...items)	要素の追加・削除・置換（破壊的）
fill(value, start, end)	範囲を値で埋める（破壊的）	配列
-	copyWithin(target, start, end)	配列内の一部をコピーして上書き（破壊的）
-	flat(depth)	ネストを平坦化（ES2019）
-	flatMap(fn)	map() + flat(1)
-	at(index)	負のインデックス対応で要素取得（ES2022）
-	with(index, value)	指定インデックスを置換した新配列（ES2023・非破壊）
-	toSorted()	ソートした新配列を返す（非破壊、ES2023）
-	toReversed()	逆順の新配列を返す（非破壊、ES2023）
-	toSpliced()	spliceの非破壊版（ES2023）
6. 注意点
破壊的 vs 非破壊的：push/pop/shift/unshift/splice/sort/reverse/fill/copyWithin は元配列を変更します。map/filter/find/slice/concat/flat/flatMap/toSorted/toReversed/with などは元配列を変更しません。
空配列・境界値：find/findIndex は見つからないと undefined / -1 を返します。
コールバック引数：多くの高階関数は (value, index, array) の順で渡します。
パフォーマンス：大きな配列では for ループが最速な場合もありますが、可読性と保守性を優先するのが一般的です。
7. ちょっとしたTips
Array.isArray() で配列かどうか判定
スプレッド構文 [...arr] や Array.from() でコピー
チェーン（メソッドチェーン）：arr.filter(...).map(...).sort(...) は非破壊的メソッド同士なら安全
some()/every() は短絡評価（条件満たした時点で終了）

必要であれば、用途別（検索・変換・集計・並び替えなど）に分類したり、具体例コードをもっと増やしたりもできます。どんな場面で困っていますか？教えていただければより的確に答えます！
