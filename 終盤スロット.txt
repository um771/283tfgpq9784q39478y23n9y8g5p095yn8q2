; ============================================================
; 終盤骨格.txt ― 構造層辞書（骨格エンジン用）
; ------------------------------------------------------------
; 「能力・ルール→対決→条件反転→犠牲・死亡→記録や名前で決着」
; への収束を防ぐため、終盤の1文を
; 「物語骨格カード（形式×決着機構×犠牲×確定度…）→ 文章化」の
; 二層で作る。対決型クライマックスは許容しつつ、
; 何が勝敗を決めるのか（決着機構）を分散させる。
;
; ■ 冒頭骨格.txt と同じ合成方式
;   局面・犠牲・死・決着・時間は、固定の一文ではなく
;   直交した部品の直積で合成する。語彙を1行足すたびに
;   掛け算で組合せが増える。
;     局面 ＝ 局面の様態 × 局面主体 × 局面動作
;     犠牲 ＝ 犠牲対象 × 犠牲帰結
;     死   ＝ 死の位置づけ × 死の主体 × 死の手段（死なれる側）
;            ＝ 死の位置づけ × 殺す主体 × 殺す手段（殺す側）
;     決着 ＝ 決着要因 × 決着帰結
;     時間 ＝ 時間の核 × 時間の接続
;   死の様式軸が死なれる側と殺す側を切り替える。
;
; ■ フォーマット・制御トークンは 冒頭骨格.txt と共通
;   #AXIS / #SLOT / #TEXT / 重みn / @軸=値 / !軸=値 / ^グループ=値 / @タグ
;   {#軸名} / {スロット名} / {スロット名?} / {スロット名@タグ}
;   文{…} / 句{…} / =文字列 / スロット名@#軸名 / スロット名「・」連結
;
; ■ 場所は指定しない
;   終盤の1文に場所名詞（学校・路上・屋上・部屋・現場・拠点・
;   階段・店舗・一本道などの固有・具体の場所）を入れない。
;   「場」「その場」「同じ場」は抽象の場であり場所指定ではない。
;   「目的地」「逃げ道」「退路」「道」は抽象の経路であり場所指定ではない。
;   合成に場所軸は作らない。時間軸は作る。
;
; ■ 甘ったれた結末の禁止
;   途中であきらめて帰る、何も起こらない、何も変わらない、
;   誰も決めない、能力を使わないまま終わる、余韻・引き分けで
;   逃げる、といった結末は辞書に入れない。該当の軸値は削除済み。
;   語彙にも去る・帰る・背を向ける・なかったことにする類を入れない。
;   犠牲「目的を諦める」は喪失の痛みとして残すが、本文の語彙に
;   「諦める」の字面は使わない（捨てる・手放す・握り潰すで書く）。
;
; ■ 人死にの直接表現
;   死の手段の語彙は、必ず「死」「殺」「命を落とす」のいずれかを
;   含むこと。殺す手段の語彙は、必ず「殺」を含むこと。
;   別れ・いなくなる・消える・去る・眠る・倒れる・
;   果てる・逝くなどのぼかし語で死を表すことを禁止する。
;   死因ごとの死の主体・死の手段・殺す主体・殺す手段は
;   @死因=… で絞り込まれる。
;
; ■ 文法の約束（直積しても破綻しないための著者ルール）
;   局面主体・死の主体・殺す主体は「〜が」で終わる。
;   局面の様態・局面動作・死の位置づけ・死の手段・殺す手段の
;   語彙に「が」「は」を入れない（「ながら」「とは」は助詞ではない）。
;   犠牲対象は「〜を」で終わる。犠牲帰結の語彙に「を」を入れない。
;   決着要因は「〜が」で終わる。決着帰結の語彙に「が」「は」を入れない。
;   決着帰結は辞書形で終わる。連結部は連用形・て形・まま・形で終わる。
;   時間の核と接続は 時間の文型（時点型・待機型）で文法を一致させる。
;
; ■ 約束ごと
;   抽選は 動的重み補正（直近履歴で出過ぎた値の重みを下げる）＋
;   リジェクション（直近カードと物語機能ベクトルが近い組は引き直し）で行う。
;   接尾部「ことになる。」は #SUFFIX が担う。
; ============================================================
